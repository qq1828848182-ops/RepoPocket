# RepoPocket

RepoPocket 是一款适用于 iOS 16+、TrollStore 的 GitHub 文件管理工具。

部分功能根据个人使用需求开发，本项目由 AI 辅助编写、编译和整理。

## 功能

- 管理多个 GitHub 账号
- 浏览仓库、分支和文件
- 新建、编辑、上传和删除文件
- 提交文件修改并查看提交记录
- 创建和切换分支
- Fork 仓库和创建新仓库
- 编辑并上传 `.deb` 插件文件
- 修改 TrollFools 插件的版本、名称、作者等信息
- 管理本地工作区文件
